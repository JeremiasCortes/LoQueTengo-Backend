# LoQueTengo

App personal para gestionar la compra y despensa de tu cocina.
Backend en Kotlin + Spring Boot, base de datos PostgreSQL.

## Estado
🚧 En desarrollo.

## Endpoints
- POST /api/v1/auth/register - Crear cuenta
- POST /api/v1/auth/login    - Iniciar sesión
- GET  /api/v1/users/me      - Mi perfil (requiere token)

## Stack
- Kotlin 2.2 + Spring Boot 4.0
- PostgreSQL
- JWT para auth
